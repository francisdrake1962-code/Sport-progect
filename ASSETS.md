# Assets Requirements

## Screenshots (3 required)

### 1. Экран "Сегодня" (screen-today.jpg)
Показать главный экран приложения:
- Календарь или текущий день недели
- Карточка урока дня с названием и длительностью
- Кнопка "Начать занятие"
- Минималистичный дизайн, чистый интерфейс
- Фон: белый/светло-серый

### 2. Экран "Подобрать занятие" (screen-configure.jpg)
Показать экран фильтрации:
- Фильтры по зоне тела (шея, поясница, колени, спина)
- Фильтры по самочувствию (взбодриться, успокоиться, лучше спать)
- Список доступных занятий с превью
- Интерактивные элементы (переключатели, чипсы)
- Фон: белый/светло-серый

### 3. Экран "Календарь" (screen-calendar.jpg)
Показать экран статистики:
- Месячный календарь с отметками пройденных дней
- Серия (streak) — сколько дней подряд
- Общая статистика (всего занятий, часов)
- Визуальное отображение прогресса
- Фон: белый/светло-серый

### Требования к скриншотам
- Формат: PNG или JPG
- Разрешение: 300×500px ( portrait mode)
- Стиль: минималистичный, соответствует лендингу
- Цвета: #2563eb (primary), #f9fafb (background), #1f2937 (text)

## Video Presentation (hero-intro.mp4)

### Концепция
Короткое видео (15-30 секунд), показывающее суть приложения.

### Структура

**Секунда 1-3:** Открытие — человек просыпается, открывает приложение на телефоне

**Секунда 4-8:** Главный экран — видно календарь с отметками, сегодняшнее занятие

**Секунда 9-15:** Занятие — человек выполняет упражнения (5-6 разных движений):
- Медленные плавные движения рук
- Наклоны и повороты
- Дыхательные практики
- Баланс

**Секунда 16-20:** Результат — человек чувствует себя лучше, улыбается

**Секунда 21-25:** Интерфейс — быстрый монтаж экранов приложения:
- Сегодня → Подобрать занятие → Календарь → Прогресс

**Секунда 26-30:** Финал — логотип + текст "7 занятий бесплатно"

### Технические требования
- Формат: MP4 (H.264)
- Разрешение: 1920×1080 или 1280×720
- Длительность: 15-30 секунд
- Без звука (мuted autoplay на лендинге)
- Цветовая палитра: синий (#2563eb), белый, серый
