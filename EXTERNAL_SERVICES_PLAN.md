## 1. ОПЛАТА — КРИТИЧЕСКИ ВАЖНО

### Текущее состояние
- На `plans.html` кнопка "Оплата скоро" — заглушка
- В БД уже есть готовые таблицы: `transactions` (subscription/one-time/refund), `promo_codes`, `next_billing_date`, `subscription_started_at`
- `checkSubscriptions()` автоматически деактивирует протухшие подписки раз в 6 часов
- **Нет ни одной строки кода для реальной оплаты**

### Вариант A: Stripe (рекомендуется)

| | |
|---|---|
| **Плюсы** | Золотой стандарт. Webhooks, подписки, управление, возвраты — всё из коробки. Отличная документация. |
| **Минусы** | 2.9% + $0.30 за транзакцию. Нужна регистрация юрлица в Stripe. |
| **Стоимость** | $0 настройки, 2.9% + $0.30/txn |
| **Что нужно** | 1. Регистрация Stripe Account  2. Создание Products (Monthly $8, Annual $89)  3. Backend: `/api/checkout` создаёт Stripe Checkout Session  4. Webhook endpoint `/api/webhooks/stripe` обрабатывает `checkout.session.completed`, `customer.subscription.updated/deleted`  5. Frontend: `plans.html` → редирект на Stripe Checkout  6. Локализация: Stripe поддерживает RUB |

### Вариант B: Lemon Squeezy

| | |

| **Стоимость** | ~5-6% за транзакцию |
| **Что нужно** | 1. Регистрация Lemon Squeezy  2. Создание продуктов  3. Backend integration (аналогично Stripe, но проще) |

### Вариант C: Ручная оплата (Telegram/перевод)

| | |

| | |

## 2. ВИДЕО — Cloudflare Stream

### Текущее состояние
- Код написан: `stream.js` генерирует подписанные токены, плеер использует HLS.js
- **Нет аккаунта Cloudflare / ключей подписи**
- Fallback: self-hosted MP4 через Express (работает, но без CDN и адаптивного битрейта)

### Проблемы self-hosted видео
1. Видео 200-500MB каждое — загрузка через Node.js процесс
2. Нет адаптивного качества (HLS) — пользователь с медленным интернетом страдает
3. Нет CDN — все на одном сервере
4. Широкополосный трафик = дорого на VPS

### Варианты

| Сервис | Стоимость | Плюсы | Минусы |
|---|---|---|---|
| **Cloudflare Stream** | $5/мес за 1000 мин хранения + $1/1000 мин доставки | Встроен в Cloudflare, JWT-подпись, HLS, глобальный CDN | Нужен CF аккаунт |
| **Mux** | $15/мес起步 | Лучшая аналитика, DRM, thumbnail API | Дороже |
| **AWS CloudFront + S3** | ~$0.02/GB | Дешевле всего при большом объёме | Нет транскодирования, сложнее настроить |
| **Self-hosted (текущий)** | $0 | Бесплатно | Нет CDN, нет HLS, bottleneck |

### Рекомендация
**Для MVP**: Self-hosted MP4 — работает, видео уже загружены.
**Для релиза**: Cloudflare Stream — $5/мес, решает все проблемы.

## 3. ПОЧТА — Email Delivery

### Текущее состояние
- **Gmail SMTP**: Настроен в `.env`, работает. Отправляет confirmation, trial expiring, subscription expiring/expired письма.
- **Resend**: Код написан, UI для ввода API ключа в админке. Нет `RESEND_API_KEY`.
- **Console**: Fallback — пишет в лог.

### Проблемы Gmail SMTP
1. Лимит 500 писем/день
2. Google может заблокировать за "подозрительную активность"
3. Письма могут попадать в Spam
4. Gmail App Password — уязвимость если `.env` в git

### Варианты

| Сервис | Стоимость | Лимиты | Плюсы |
|---|---|---|---|
| **Gmail SMTP (текущий)** | $0 | 500/день | Бесплатно, настроено |
| **Resend** | $0 до 100 писем/день, $20/мес — 50K | 100-50K/мес | Уже интегрирован в код, modern API |
| **SendGrid** | $0 до 100/день | 100-100K/мес | Популярный, шаблоны |
| **AWS SES** | $0.10/1000 писем | Без лимита | Дешевле всего при масштабе |

### Рекомендация
**Для MVP**: Gmail SMTP — работает, 500/день достаточно для старта.
**Для релиза**: Resend — код уже написан, нужно только получить API ключ.

## 4. ENVIRONMENT & SECURITY — ДО РЕЛИЗА

### Обязательно перед запуском

| Что | Статус | Действие |
|---|---|---|
| `APP_BASE_URL` | `localhost:3001` | Заменить на реальный домен |
| `JWT_SECRET` | Слабый hex | Сгенерировать 256-bit ключ |
| `.env` в git | **Уязвимость** | Добавить `.env` в `.gitignore`, проверить git history |
| `ALLOWED_ORIGIN` | Не задан | Установить домен для CORS |
| `NODE_ENV` | Не задан | Установить `production` |
| CSP | `unsafe-inline` | Убрать inline scripts (перенести в файлы) |

### Рекомендуемый порядок запуска

```
1. Регистрация домена + DNS
2. Настройка VPS / Railway / Render
3. .env: APP_BASE_URL, JWT_SECRET (256-bit), ALLOWED_ORIGIN, NODE_ENV=production
4. Gmail SMTP → работает сразу
5. Self-hosted MP4 → работает сразу  
6. Ручная оплата → нулевая интеграция
7. === MVP готов ===
8. Post-launch: Stripe интеграция
9. Post-launch: Cloudflare Stream ($5/мес)
10. Post-launch: Resend ($0起步)
```

## 5. ТЕХНИЧЕСКИЕ ДОЛГИ

| Что | Приоритет | Описание |
|---|---|---|
| CSP `unsafe-inline` | P2 | Все standalone-страницы используют inline JS. Нужно вынести в webpack bundles. |
| localStorage tokens | P2 | XSS-exfiltratable. Перейти на httpOnly cookies. |
| Admin HTML routes без auth | P3 | `/admin/*.html` доступны без JWT (защита только на клиенте). |
| hls.js pinned version | P1 | Закрепить версию (1.6.16) для предсказуемости. |
| `<noscript>` только на 5 страницах | P3 | Добавить на остальные JS-dependent страницы. |
