## 1. ОПЛАТА — КРИТИЧЕСКИ ВАЖНО

### Текущее состояние
- На `plans.html` кнопка "Оплата скоро" — заглушка
- В БД уже есть готовые таблицы: `transactions` (subscription/one-time/refund), `promo_codes`, `next_billing_date`, `subscription_started_at`
- `checkSubscriptions()` автоматически деактивирует протухшие подписки раз в 6 часов
- **Нет ни одной строки кода для реальной оплаты**

### Решение (уточнение 2026-07-31): Stripe Thailand на тайского гражданина

**Уточнение клиента:** счёт и банковский аккаунт в Таиланде открыты **на местного гражданина** (тайца). Это снимает главный барьер — Stripe Thailand на тайца как **Individual / Sole Proprietorship** работает: тайский ID, адрес, THB-счёт всё сходится. Комиссия **~2.9% + $0.30** — в ~2.5 раза дешевле MoR. Платёжный код проекта уже Stripe — **переписывать не нужно**, только ключи аккаунта тайца.

**Проверено по официальным источникам (2026-07-31):**
- ✅ Stripe Thailand поддерживает Sole Proprietorship и Individual (Stripe support).
- ✅ **AML**: BOT-детекция «мулов» — коммерческие выплаты из-за рубежа на личный счёт = риск блокировки. Нужен **бизнес-счёт** (sole proprietorship → Tax ID → бизнес-счёт).
- ✅ **Налоги тайца**: PIT 0–35% (резидент); VAT 7% — только при обороте >1.8M THB/год, регистрация в течение 30 дней; экспорт услуг — возможна 0%.
- ⚠️ **Nominee-риск**: реальный партнёр (супруг/семья) — ок; номинальный держатель для иностранца — риск AMLA/DBD Order 1/2569 (уголовка, заморозка счетов, blacklist).
- ⚠️ App Store: 15% только через Small Business Program (<$1M) или после года подписки; стандарт 30%. iOS-цифровой контент = IAP обязателен.

**Порядок:**
1. Регистрация sole proprietorship на тайца + Tax ID + **бизнес-счёт**.
2. Stripe Thailand (Individual/SP) → ключи в проект; пересмотреть цены в USD/EUR.
3. Консультация тайского бухгалтера: PIT, VAT-порог, экспорт-0%, оформление отношений с тайцем.
4. AppStore Small Business Program заявка (15%).
5. **Резерв (если Stripe откажет):** Lemon Squeezy (~5–8%, банк-выплаты в Таиланд подтверждены) или Paddle / Dodo.

### Отклонено
- **Вариант D: YooKassa** — только для РФ; аудитория зарубежная (ЕС/US), Про́дамус (~10%) тоже отклонён.
- **Вариант C: Ручная оплата** — не масштабируется, оставлен как fallback.
- Opn/Omise, 2C2P, Xendit — тайские PSP, в основном для тайских компаний; как физлицо-иностранец скорее не пройти.

## 2. ВИДЕО — Cloudflare Stream

### Текущее состояние
- Код написан: `stream.js` генерирует подписанные токены, плеер использует HLS.js
- **Нет аккаунта Cloudflare / ключей подписи**
- Fallback: self-hosted MP4 через Express (работает, но без CDN и адаптивного битрейта)

### Проблемы self-hosted видео
1. Видео 200-500MB каждое — загрузка через Node.js процесс
2. Нет адаптивного качества (HLS) — пользователь с медленным интернетом страдает
3. Нет CDN — все на одном сервере
4. Широкополосный трафик = дорого на VPS

### Решение (2026-07-31): Mux → Bunny Stream; Cloudflare Stream вычеркнут

**Почему не Cloudflare Stream:** дорого на этом объёме ($5/мес за 1000 мин хранения + $1/1000 мин доставки).

**План:**
| Сервис | Стоимость | Плюсы | Минусы |
|---|---|---|---|
| **Свой сервер** (бесплатные уроки, 720p) | $0 (VPS-диск + трафик) | Без рекламы, полный контроль, уже работает (`/videos/*` + stream-токен + Range) | Трафик на VPS; при росте → Bunny CDN |
| **Mux** (платные уроки, старт) | 100K мин доставки бесплатно, PAYG: delivery $0.0008/мин (720p), storage $0.0024/мин/мес, encoding $0, player+analytics $0, $20/мес кредит | Стриминг 180 уроков (~75ч хранения ≈ $10.8/мес — внутри кредита) | Free-план хранит только 10 видео — нужен PAYG |
| **Bunny Stream** (при росте) | ~$0.01/GB доставка, без ежемес. платы, signed URLs | Дёшево при объёме | Меньше аналитики |

**Бесплатные уроки — БЕЗ YouTube (решение 2026-07-31):** YouTube-embed отклонён из-за рекламы (для пожилой аудитории — риск оттока; гарантии отсутствия рекламы нет даже на немонетизированном канале — YouTube может показывать её сам). Бесплатные уроки → **со своего сервера 720p** (скрипт `server/scripts/encode-720p.js`, файлы в `videos/`, `video_url` в БД). YouTube остаётся только маркетинговым каналом (публичные превью для воронки Facebook/email). Платные → Mux (рекламы нет в принципе).

**Триггер перехода на Bunny:** когда доставка превысит ~100K мин/мес (~3 333 полных просмотров по 30 мин). Рез: 720p-кэп на доставку для снижения цены.

## 3. ПОЧТА — Email Delivery

### Текущее состояние
- **Gmail SMTP**: Настроен в `.env`, работает. Отправляет confirmation, trial expiring, subscription expiring/expired письма.
- **Resend**: Код написан, UI для ввода API ключа в админке. Нет `RESEND_API_KEY`.
- **Console**: Fallback — пишет в лог.

### Проблемы Gmail SMTP
1. Лимит 500 писем/день
2. Google может заблокировать за "подозрительную активность"
3. Письма могут попадать в Spam
4. Gmail App Password — уязвимость если `.env` в git

### Варианты

| Сервис | Стоимость | Лимиты | Плюсы |
|---|---|---|---|
| **Gmail SMTP (текущий)** | $0 | 500/день | Бесплатно, настроено |
| **Resend** | $0 до 100 писем/день, $20/мес — 50K | 100-50K/мес | Уже интегрирован в код, modern API |
| **SendGrid** | $0 до 100/день | 100-100K/мес | Популярный, шаблоны |
| **AWS SES** | $0.10/1000 писем | Без лимита | Дешевле всего при масштабе |

### Рекомендация
**Для MVP**: Gmail SMTP — работает, 500/день достаточно для старта.
**Для релиза**: Resend — код уже написан, нужно только получить API ключ.

## 4. ENVIRONMENT & SECURITY — ДО РЕЛИЗА

### Обязательно перед запуском

| Что | Статус | Действие |
|---|---|---|
| `APP_BASE_URL` | `localhost:3001` | Заменить на реальный домен |
| `JWT_SECRET` | Слабый hex | Сгенерировать 256-bit ключ |
| `.env` в git | **Уязвимость** | Добавить `.env` в `.gitignore`, проверить git history |
| `ALLOWED_ORIGIN` | Не задан | Установить домен для CORS |
| `NODE_ENV` | Не задан | Установить `production` |
| CSP | `unsafe-inline` | Убрать inline scripts (перенести в файлы) |

### Рекомендуемый порядок запуска

```
1. Регистрация домена + DNS
2. Настройка VPS / Railway / Render
3. .env: APP_BASE_URL, JWT_SECRET (256-bit), ALLOWED_ORIGIN, NODE_ENV=production
4. Gmail SMTP → работает сразу
5. Видео: свой сервер (free, 720p) + Mux (paid, 720p-кэп) — YouTube только маркетинг
6. Lemon Squeezy: заменить Stripe-интеграцию, hosted checkout → подписки
7. === MVP готов ===
8. При росте >100K мин/мес: переезд доставки на Bunny Stream
9. Post-launch: Resend ($0起步)
```

## 5. ТЕХНИЧЕСКИЕ ДОЛГИ

| Что | Приоритет | Описание |
|---|---|---|
| CSP `unsafe-inline` | P2 | Все standalone-страницы используют inline JS. Нужно вынести в webpack bundles. |
| localStorage tokens | P2 | XSS-exfiltratable. Перейти на httpOnly cookies. |
| Admin HTML routes без auth | P3 | `/admin/*.html` доступны без JWT (защита только на клиенте). |
| hls.js pinned version | P1 | Закрепить версию (1.6.16) для предсказуемости. |
| `<noscript>` только на 5 страницах | P3 | Добавить на остальные JS-dependent страницы. |
